# Agent model routing with Jev

Run `node scripts/route-agent-task.mjs "Short, nonsensitive task summary"` from this repository. The helper reads `TYPESAFE_API_KEY` from the process environment or the root `.env` and calls TypeSafe's direct [System One API](https://docs.typesafe.ai/api) with pinned model `jev-1.13.0`. There is no other provider fallback. The pinned version keeps routing thresholds stable; review the [model list](https://docs.typesafe.ai/models) before upgrading. Jev returns a typed classification, not generated work. An agent or human reviews the recommendation and chooses the actual worker model; this script cannot switch the current conversation's model.

Use only a short plain-language summary. Never include source code, planner data, personal information, secrets, or raw logs. The script rejects common accidental code and credential patterns, but the person calling it must still screen the summary. It prints only the recommended model, effort, and a fixed reason code; it does not print the summary, key, API body, or network error.

Routing policy: clear small mechanical tasks use `gpt-6-sol` Low; ordinary work uses `gpt-6-sol` Medium; important, difficult, high-risk, ambiguous, or uncertain work uses `gpt-6-sol` High. The helper never selects Luna, Terra, or Astra. A local high-risk keyword guard selects SOL High before an API call. Astra requires explicit user approval outside this tool. Missing credentials, network/API failures, malformed responses, and low confidence all fall back to SOL High. The confidence thresholds are conservative heuristics, not proof of classification accuracy. Review outcomes and tune thresholds only against labeled examples from this workflow.

`--dry-run` validates the summary and reports the fallback without a network request. Run `node --test --test-isolation=none scripts/route-agent-task.test.mjs` for mocked tests. This is an agent workflow utility only; it is not connected to the planner app, build, deployment, or runtime.
